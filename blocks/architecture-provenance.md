<!--
  Provenance line for an architecture diagram. Goes immediately under the diagram,
  with no blank section between them.

  Variables, all from manifest/portfolio.yaml or the checkout:
    $generator   the tool and how it was run, e.g. "gitdiagram (gitdiagram.com)"
    $commit      registry architecture_diagram_commit — the sha the graph was generated from
    $generated   registry architecture_diagram_generated — YYYY-MM-DD
    $caveat      the generator's OWN declared limitation, quoted, not paraphrased

  $caveat is not optional decoration. gitdiagram samples a bounded set of source
  excerpts and says so; its overview for warehouse_humanoid_tco ends "Some orchestration
  internals are unsampled, so only README- or source-supported relationships are shown."
  A statement like that is evidence about the evidence. The hierarchy in the standard
  (source -> computation -> artifact -> interpretation -> claim) requires it to be carried
  forward to the reader, not dropped at the point where the artifact becomes a picture.
  If the generator declared no caveat for this run, say so explicitly rather than
  omitting the clause.
-->
